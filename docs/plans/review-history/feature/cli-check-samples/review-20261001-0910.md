2. **[crates/cli/src/main.rs:609]**: `collect` recurses on `path.is_dir()`, which follows symlinks and Windows junctions. A link back to an ancestor folder (or a junction loop in a sample tree) makes the walk recurse until the stack overflows. It also counts the same files twice when two links point at one folder. Use `entry.file_type()` and recurse only when `ft.is_dir()`, which does not follow links. Either skip symlinked dirs or report them. That also saves the extra `stat` per entry.
3. **[crates/cli/src/main.rs:57-59]**: The new usage line is added by putting a literal newline (plus seven spaces of indentation) inside the string. Every other line break in that same string is a `\n` escape. The output is the same, but the mixed style is easy to break on a later edit, because re-indenting the source line changes the printed text. Append `\n       riffle-cli check <dir>... [threads]` on the existing line, matching the other entries.
