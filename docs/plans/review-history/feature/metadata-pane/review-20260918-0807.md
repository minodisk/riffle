### Findings

1. **crates/core/src/reader.rs:64**: The whole-file fallback surfaces the *prefix* error (`.map_err(|_| e)`), which is the opposite of what `read_preview` does a few lines above and of the reason documented there ("once the whole file is in memory, an error there describes what is actually wrong with the file, so surface that one instead"). Drop the `map_err` so `read_metadata` returns the whole-file error too, keeping the two paths consistent.
2. **crates/app/src/commands.rs:148**: `decimal` trims trailing zeros unconditionally, so it is only correct while `places >= 1` guarantees a `.` in the formatted text. With `places = 0` (or any integral value formatted without a fractional part) `100` becomes `1`. Since `places` is a parameter, guard it: only trim when `text.contains('.')`. A test for the integral case would pin it down.
