### Findings

1. **crates/app/src/main.rs:71**: `tauri_plugin_log::Builder::new().build()` uses the plugin's default max level, `LevelFilter::Trace`, with no per-crate filter. Distributed builds will therefore write trace/debug output from every dependency (tao, wry, tauri internals, and the updater's HTTP stack) to stdout and to the log file. The file rotates at a small size, so this noise pushes out the app's own `log::error!`/`log::warn!` lines, and those lines are why the plugin was added. Set an explicit level, e.g. `.level(log::LevelFilter::Info)`, or `Debug` under `cfg!(debug_assertions)` and `Info` otherwise. Optionally add `.level_for(...)` for any crates that are still noisy at that level.
