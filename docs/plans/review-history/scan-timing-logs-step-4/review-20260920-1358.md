2. **README.md:83-85 (`Riffle_<timestamp>.log` beside it once the current one has rotated)**: the app does not set `rotation_strategy`, so `tauri-plugin-log` uses its default `RotationStrategy::KeepOne`, which deletes the old file on rotation instead of renaming it (`tauri-plugin-log-2.9.1/src/lib.rs:52,242`). A dated `Riffle_<timestamp>.log` never appears. Either drop the parenthetical, or say that on rotation (at the 1 MB cap set in `crates/app/src/main.rs:328`) the previous contents are discarded — which is also the more useful warning for someone measuring a long scan.
