The command accepts several `<dir|file>` inputs, so two inputs with the same stem collide. That happens with two folders that both hold `_DSC0001.ARW`, or with `X.ARW` and `X.DNG` side by side. Under `par_iter` both files then write the same PNGs concurrently: one silently overwrites the other, and the two index lines cannot be told apart. Before the run, check `paths` for duplicate stems and `bail!` if there are any, the way `raw_paths` already rejects bad inputs. Alternatively, prefix the crops and index lines with something unique, such as the input index or the parent folder name.
