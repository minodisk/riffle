1. **crates/cli/src/main.rs:123-127**: `bench` lost the preview skip. The old `if let Some(e) = a.preview` silently skipped a file with no embedded preview; `reader::read_preview(path)?` now aborts the whole batch on the first such file, so one preview-less DNG/ARW in a large batch kills the run and discards all timings. The plan only sanctioned the `a.full` gate and said nothing about dropping this one, so this is an unsanctioned behavior change. Restore the skip, e.g. read the metadata first and gate on it: `let a = reader::read_metadata(path)?; if a.preview.is_none() { continue; }` (or match on the `read_preview` error and `continue`), keeping the existing `a.full.is_some()` gate for the full/crop timings. Note that `continue` should skip the whole iteration only if `a.full` also cannot be decoded without a preview; if `full` is independent, prefer gating each timing separately so a preview-less file still contributes full/crop numbers.
2. **docs/plans/20260921-cli-bounded-reads/plan.md:56-63**: Step 1 is checked off but `## Progress` still reads `- (none yet)`. The plan's own `<pr-rules>` require the implementation PR to include both the checkbox and the Progress entry. Add the Step 1 Progress entry.
