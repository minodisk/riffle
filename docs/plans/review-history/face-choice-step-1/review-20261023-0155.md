Alternatively, limit the crop-set comparison to AF frames and add a separate check of the fallback on the no-AF frames. Step 2's done-when in `plan.md` (line 223, "The rows of the crop set's `nearest` face reproduce ...") has the same wording and needs the same fix.

Today the point is `Detection::point` from `detect_around_rgb`, which is `partial::focus_point(width, height, focus)` in stored coordinates (`faces.rs:523`). `detect_whole_upright` sets `point: None` (`faces.rs:476`), so the whole set has no point of its own. Pin it to the crop detection's stored `focus_point`, the one `nearest_face` uses today and the one Step 2's `af_x` / `af_y` columns record. Then "only the detection changes" holds by construction and is not left to the implementation.
