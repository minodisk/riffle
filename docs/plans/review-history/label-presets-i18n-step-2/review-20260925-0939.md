Tab goes straight from the Purple input to Reset, and a keyboard user can never reach the language dropdown. That leaves Reset stuck on the default (English) preset unless the user clicks the dropdown with the mouse. Add `select` to the selector (e.g. `"button, input, select, [tabindex]"`). If the `disabled` filter should apply to it too, widen the cast accordingly.
