2. **README.md:199-201 (and README.ja.md:136)**: The claim that "a burst spanning a second boundary can be split" can't happen with the current grouping. `groupBursts` in `crates/app/ui/src/burst.ts` starts a new burst only when `ms - previous > 1000`. With whole-second capture times, two frames taken at most 1 s apart are always 0 or 1000 ms apart after truncation, and this holds with rounding too. So a real burst is never split. The only failure mode is over-joining, where two frames up to about 2 s apart share a burst; the "shot taken right after a burst can join it" half is correct. The `BURST_GAP_MS` comment ("anything below 1 s would split every Leica burst") says the threshold was chosen for exactly this reason. Drop the split clause in both files, e.g. "Without it, frames are grouped by whole seconds, so a shot taken up to about 2 s after the previous frame can still join its burst." In Japanese, remove 「1 秒をまたぐ連写が分かれたり、」 and rephrase the rest to match.
