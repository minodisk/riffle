## Round 1

**Reviewed commit**: `575a91d1224cc3ddd4a2edcdce4e9d306ad9c07b` feat(app): draw ARW previews on a canvas with arrow-key paging

STATUS: NEEDS_FIX

### Findings

1. **crates/app/ui/src/main.ts:97-104 (`show`)**: every keydown fires an `invoke("preview", ...)` and nothing bounds the number in flight. The sequence counter only discards the *results*; the requests themselves all keep running. Holding `ArrowRight` across a 5000-file folder (exactly the acceptance case that could not be demonstrated) issues one request per auto-repeat, and each one lands in `tauri::async_runtime::spawn_blocking` doing a `std::fs::read` of a ~48 MB ARW (`crates/app/src/commands.rs:60-68`). With the blocking pool's default size that is many tens of full-file buffers alive at once — the app will at best lag far behind the key, at worst exhaust memory on the user's first real run. Keep at most one request outstanding: remember the currently requested index, and when a response settles, if `index` has moved on since, issue exactly one follow-up for the latest `index`. The existing stale-response checks stay as they are; this only stops the queue from growing.

### Findings

1. **crates/app/ui/src/main.ts:81-112 (`requestPreview`)**: the new follow-up path can fire when there is no file to request. `openFolder` bumps `seq` and, when `list_arw` returns an empty array, sets `files = []`, calls `setStatus()` ("No ARW files in that folder.") and returns without calling `show()`. If a `preview` invoke from the previous folder is still outstanding at that moment (likely — it is a ~48 MB `std::fs::read`), it settles with `current !== seq` and unconditionally calls `requestPreview()`, which now invokes `preview` with `path: files[0] === undefined`. The invoke rejects, and the `catch` overwrites the status line with a deserialization error instead of the empty-folder message. Guard the issue site, e.g. `if (inFlight || files.length === 0) { return; }` at the top of `requestPreview` — `move()` already has the same guard, so this is the only reachable hole.
