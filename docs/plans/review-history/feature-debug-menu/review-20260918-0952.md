# Review history: feature/debug-menu

## Round 1

**Reviewed commit**: `0faa8171bd71b7ef1aafe968a6938b4ff218575f` feat(app): toggle timing logs from a Debug menu

STATUS: APPROVED

The `#[cfg(any(feature = "devtools", debug_assertions))]` gating is airtight (`cargo clippy -p riffle-app --all-targets` and the same with `--release` are both warning-free, so nothing leaks into a distributable build), the menu is built from `Menu::default` and the appended `Timing logs` item carries no accelerator, so none of the webview's plain-key bindings are shadowed. The frontend change is additive and localized, `debugLog` short-circuits on a `false` flag with only trivially cheap arguments at the three call sites, and no new dependency, schema, or `index.rs` change came along.
