Canon と Nikon のカメラでは、Riffle は AF 点をメーカーノート（`AFInfo2`）から読みます。複数の AF 点にピントが合っている場合は、マークがそのすべてを囲みます。Nikon Z 8 と Canon EOS R6 のサンプルには AF 位置がなかった（自動エリアで一度も合焦しなかったものと、マニュアルフォーカスのもの）ため、この 2 機種は未確認です。Nikon D850 と D500 は Riffle が読まない古い `AFInfo2` を書き込みます。

HDR PQ をオンにして撮った CR3 ファイル（HEIF）には、JPEG の代わりに HEVC の画像が入っています。Riffle は 1620x1080 の HEVC プレビューをデコードして sRGB にトーンマッピングするので、ほかのファイルと同じようにサムネイル、プレビュー、シャープネスのスコアが得られます。フルサイズの画像はデコードしないため、こうしたファイルの等倍表示（`z`）はセンサーの画素ではなく、1620x1080 のプレビューを切り出したものになります。

Fujifilm のカメラでは、Riffle は AF 点をメーカーノート（`FocusPixel`）から読みます。これは枠のサイズを持たない点です。X-T3 と GFX 100 のサンプルはすべてマニュアルフォーカスで撮られていて、Riffle はそれを AF 点なしとして扱うため、この 2 機種は未確認です。X-A2、X-E3、X100F、XF10、GFX 50S のサンプルも同様です。1 秒未満の撮影時刻は、サンプルに記録されていたとおりに印を付けています。古い X シリーズと FinePix のカメラはどれも記録しません。

RAF にはセンサーの解像度より小さい埋め込み JPEG が 1 つ入っています。どの Fujifilm のカメラでも、これがプレビューと等倍表示になります。等倍表示はセンサーの画素ではなく、その JPEG を元のサイズで表示します。古い X シリーズと FinePix のカメラも開けますが、埋め込み JPEG が 1920x1280 から 2176x1448 なので、等倍表示は画素レベルの確認ではなく、その小さな JPEG になります。

ORF にはセンサーの解像度より小さい埋め込み JPEG が 1 つ入っていて、ここに載せたどのカメラでも 3200x2400 です。ORF の等倍表示はセンサーの画素ではなく、その JPEG を元のサイズで表示します。

OM System と Olympus のカメラでは、Riffle はまだ AF 点を読みません。メーカーノートには `AFTargetInfo`（OM のカメラ）と `AFPointSelected` として記録されていますが、これは今後の対応です。これらのカメラのサンプルはどれも 1 秒未満の撮影時刻を記録していないので、連写は秒単位でまとまります。高いコマ速で撮った連写は、1 秒の中で分けられません。

Sony α9 III と α7CR のサンプルはすべてマニュアルフォーカスで撮られていて、Riffle はそれを AF 点なしとして扱うため、この 2 機種は未確認です。残りの Sony のカメラで、顔追尾の列の `–` は、そのカメラのサンプルに顔追尾が記録されていなかったという意味で、カメラにその機能がないという意味ではありません。顔追尾が記録されていても、枠の下に顔があるとは限りません。α6700 のサンプルのうち 2 枚は、何もない背景と、市場の屋台に並んだパンの上に枠があるのに顔追尾を記録しています。また、AF 点がちょうどセンサーの中心にあるときは追尾が一度も合焦しなかったものとして、Riffle は枠を無視します。

Sony α9 II、α7R IV、α7R IVA、α7C、α6400、α6600、ZV-E10 にはフルサイズの埋め込み JPEG がなく、1616x1080 のプレビュー（ZV-E10 は 1920x1080）と 160x120 のサムネイルしか入っていません。これらのカメラの等倍表示は、ORF と同じく、センサーの画素ではなくそのプレビューを元のサイズで表示します。

- **AF 点**: フォーカスマークがそこに描かれ、等倍ピントチェックがそこを中心に開き、シャープネスはその周辺で測ります。このとき顔は、AF 点がどの顔の外にあっても無視します。AF 点がなければフォーカスマークは表示されず、等倍ピントチェックは画面の中心で開き、シャープネスは検出した顔の両目の間で、顔がなければ最もシャープな領域で測ります。フォーカスモードを記録するカメラ（Sony）でマニュアルフォーカスで撮った写真は AF 点なしとして扱います。DMF で撮った写真と、フォーカスモードを記録しないカメラの写真はそう扱いません。
- **AF 枠のサイズと顔追尾**: 両方があれば、シャープネスはカメラの瞳 AF 枠で測ります。顔検出に頼らないので、これが最も確実です。これはセレクトに役立ちます。各サムネイルの横にあり、連写の中で最もシャープなコマを示すシャープネスのバーが、カメラがピントを合わせた目で測られるので、Riffle 自身の顔検出が顔を見逃しても、背景や服のほうがシャープなコマではなく、目がシャープなコマが最もシャープになります。AF 枠のサイズがない顔追尾には、この利点はありません。シャープネスはいつもどおり AF 点の周辺で測ります。どちらもフォーカスマークの色は変えません。マークの色を決める、AF 点に最も近い顔の目にピントが合っている確率は、Riffle の顔検出から求めます。α7 V では、AF が後頭部にあるときも `Face tracking` が記録されます。これはカメラが人の頭を認識したという意味で、厳密に顔や目を認識したという意味ではありません。メタペインの `AF tracking` の行にこの値が表示されます。
- **1 秒未満の撮影時刻**: 直前のコマから 1 秒以内のコマが連写になります。これがない場合はコマを秒単位でまとめるので、直前のコマから 2 秒近く後に撮った写真も同じ連写に入ることがあります。
